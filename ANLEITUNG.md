# Sport-Liste – Anleitung

## 1. Auf GitHub hochladen
1. Auf github.com ein neues Repository anlegen, z. B. `sportliste`.
2. „Add file → Upload files“ und diese 5 Dateien hochziehen:
   index.html, sw.js, manifest.json, apple-touch-icon.png, icon-512.png
3. Settings → Pages → Branch `main`, Ordner `/ (root)` → Save.
4. Nach 1–2 Minuten läuft die App unter `https://timmbeau.github.io/sportliste/`.

## 2. Aufs iPad
1. Den Link in **Safari** öffnen.
2. Teilen-Symbol → „Zum Home-Bildschirm“.
3. Die App **ab jetzt immer über das Symbol** öffnen (Safari und Home-Bildschirm-App haben getrennte Speicher).

## 3. Einrichten
Einstellungen → Klassenliste einfügen → Speichern. Fertig.
Weitere Klassen (z. B. 9a/9b) unter „Weitere Klasse“.

## Datenschutz
Die Namen und Einträge stehen NICHT im Code auf GitHub, sondern werden nur auf dem iPad gespeichert.
Ab und zu unter Einstellungen → „Sicherung speichern“ eine Sicherung in „Dateien“ ablegen.
